ระบุลิ้งก์ Google Sheets Published CSV

วิธีเผยแพร่ Google Sheets เป็น CSV:

  1. ไปที่ไฟล์ Google Sheets ของคุณ
  2. คลิก File (ไฟล์) > Share (แชร์) > Publish to Web (เผยแพร่ไปยังเว็บ)
  3. เปลี่ยนรูปแบบจาก Web page เป็น Comma-separated values (.csv)
  4. กด "เผยแพร่" คัดลอกลิ้งก์นำมาวางที่นี่

ขั้นตอนการนำขึ้น GitHub Pages (ใช้งานฟรี 100%)

สร้างแดชบอร์ดออนไลน์ให้ทีมงานเข้าดูได้ตลอดเวลา

ขั้นตอนที่ 1: บันทึกไฟล์

บันทึกโค้ดหน้านี้เป็นไฟล์ชื่อ index.html ลงในคอมพิวเตอร์

ขั้นตอนที่ 2: สร้าง Repository บน GitHub

เข้า GitHub.com กดสร้าง Repository ตั้งชื่อโปรเจกต์ (เช่น public-health-dashboard) และตั้งค่าเป็น Public

ขั้นตอนที่ 3: อัปโหลด index.html

กดปุ่ม Upload files ลากไฟล์ index.html วางลงไป แล้วกด Commit changes

ขั้นตอนที่ 4: เปิดใช้งาน Pages

ไปที่เมนู Settings > Pages เลือก Branch เป็น main โฟลเดอร์ / (root) กด Save รอ 1 นาที จะได้ URL เว็บไซต์แชร์ใช้งานได้ทันที
